## Problem

Many DePIN token launches reward wallets before validating useful participation. PHN is designed around the opposite flow: users should connect a wallet, prepare peaq network access, activate a human-operated node, bind identity, and then participate through transparent staking and reward flows.

## Protocol Model

PHN is built around verified-human node participation:

- Machine fingerprint: the node workflow prepares a hardware or device identity layer.
- Human attestation: users must be treated as real operators rather than anonymous farming wallets.
- peaq DID binding: peaq identity infrastructure is the primary identity direction for the protocol.
- Heartbeat participation: verified nodes are expected to send periodic heartbeats before rewards are considered valid.
