# Tokenomics

| Bucket | Allocation | Purpose |
|---|---:|---|
| Founder / owner | 50,000,000 PHN | 50% ownership exactly as requested, held in founder vesting wallet |
| Ecosystem treasury | 20,000,000 PHN | partnerships, grants, listings, operations |
| Node rewards | 20,000,000 PHN | incentive pool for verified operators |

## Control recommendations before mainnet
- move admin roles to a multisig
- route privileged actions through the deployed timelock
- publish wallet labels for all buckets
- avoid undisclosed mint paths; the current token has a fixed supply only
