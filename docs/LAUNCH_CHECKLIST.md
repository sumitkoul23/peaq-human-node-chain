# Launch checklist

## Before BSC testnet deployment
- confirm owner wallet
- confirm ecosystem treasury wallet
- confirm liquidity vault wallet
- choose founder vesting start and duration
- choose timelock delay
- run `npm test`

## Before BSC mainnet deployment
- deploy and verify on testnet
- publish tokenomics and wallet labels
- move admin ownership to multisig
- review founder vesting and timelock parameters
- complete external contract review
- prepare incident response runbook

## Before omnichain launch
- deploy OFT contracts on every target chain
- configure peers in both directions
- test send/receive paths
- reconcile global supply
- enable monitoring and pause controls
