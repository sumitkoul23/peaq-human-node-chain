Activate a PHN Node

Windows

npm run phn-node -- init\nnpm run phn-node -- set-operator 0xYourWallet\nnpm run phn-node -- set-did did:peaq:your-machine\nnpm run phn-node -- doctor\nnpm run phn-node -- registration-payload

macOS

npm run phn-node -- init\nnpm run phn-node -- set-operator 0xYourWallet\nnpm run phn-node -- set-did did:peaq:your-machine

Linux / Ubuntu

sudo apt update\nsudo apt install -y git nodejs npm\nnpm run phn-node -- init\nnpm run phn-node -- doctor

Mobile app

Install PHN Beacon, connect wallet, verify device, attach machine DID, start node mode, keep heartbeat active, and claim rewards.
